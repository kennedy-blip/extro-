# Extro (pairextro)

A modern, modular software application built collaboratively from scratch.

## Overview

Extro is designed with clean architecture principles, emphasizing high modularity, testability, and developer ergonomics.

## Features

- **Modular Architecture**: Decoupled core modules for easy maintainability and extensibility.
- **Robust Tooling**: Configured with strict linting, formatting, and build pipelines.
- **Collaborative Engineering**: Developed pair-programming style with full co-author tracking.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v20+ recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation

```bash
npm install
```

### Running the Application

```bash
npm start
```
